Configuração necessária

O recurso de amigos requer duas tabelas no Supabase. Execute o SQL abaixo no SQL Editor do seu projeto Supabase: 

-- Tabela de perfis (sincronizada com auth.users)
CREATE TABLE IF NOT EXISTS public.profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  full_name TEXT,
  email TEXT,
  updated_at TIMESTAMPTZ DEFAULT now()
);
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Perfis visíveis a todos" ON public.profiles FOR SELECT USING (true);
CREATE POLICY "Usuário edita próprio perfil" ON public.profiles FOR UPDATE USING (auth.uid() = id);

-- Trigger para criar perfil automaticamente no signup
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS TRIGGER LANGUAGE plpgsql SECURITY DEFINER AS $$
BEGIN
  INSERT INTO public.profiles (id, full_name, email)
  VALUES (NEW.id, NEW.raw_user_meta_data->>'full_name', NEW.email)
  ON CONFLICT (id) DO NOTHING;
  RETURN NEW;
END;
$$;
CREATE OR REPLACE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();

-- Tabela de amizades
CREATE TABLE IF NOT EXISTS public.friendships (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  requester_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  addressee_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','accepted')),
  created_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(requester_id, addressee_id)
);
ALTER TABLE public.friendships ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Usuários veem próprias amizades" ON public.friendships FOR SELECT
  USING (auth.uid() = requester_id OR auth.uid() = addressee_id);
CREATE POLICY "Usuário cria pedido" ON public.friendships FOR INSERT
  WITH CHECK (auth.uid() = requester_id);
CREATE POLICY "Destinatário aceita pedido" ON public.friendships FOR UPDATE
  USING (auth.uid() = addressee_id OR auth.uid() = requester_id);
CREATE POLICY "Partes podem remover" ON public.friendships FOR DELETE
  USING (auth.uid() = requester_id OR auth.uid() = addressee_id);
Guia de Modelos de Regressão
Entenda quando e como usar cada modelo disponível na plataforma. Escolha o modelo certo para o seu problema e obtenha análises mais precisas e interpretáveis.
7 modelos disponíveis Regressão Contínua Classificação Séries Temporais
📈
Regressão Linear Simples ↗ Regressão contínua · 1 variável
O que é
O modelo mais fundamental da estatística. Estima a relação linear entre uma variável independente (X) e uma variável resposta contínua (Y) usando o método dos Mínimos Quadrados Ordinários (OLS), minimizando a soma dos quadrados dos resíduos.
Fórmula
Ŷ = β₀ + β₁·X + ε
β₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
Quando usar
Prever o salário de um profissional com base em anos de experiência
Estimar o consumo de energia a partir da temperatura
Analisar a relação entre preço e demanda de um produto
Métricas principais
R² R² Ajustado p-valor IC 95% F-estatístico Cook's Distance
Nível: Iniciante
📊
Regressão Múltipla ↗ Regressão contínua · N variáveis
O que é
Extensão da regressão linear para múltiplos preditores. Usa álgebra matricial (OLS) para estimar o efeito individual de cada variável controlando as demais. Inclui diagnóstico de multicolinearidade via VIF.
Fórmula
Ŷ = β₀ + β₁X₁ + β₂X₂ + … + βₙXₙ
β = (XᵀX)⁻¹Xᵀy
Quando usar
Prever o preço de imóveis usando área, quartos e localização
Modelar a produtividade com fatores climáticos, solo e insumos
Analisar vendas considerando preço, publicidade e sazonalidade
Métricas principais
VIF R² Ajustado t-teste por β F-global ANOVA
Nível: Básico
🎯
Regressão Logística ↗ Classificação binária · 0 ou 1
O que é
Modela a probabilidade de um evento binário ocorrer. Usa a função sigmoide para restringir a saída entre 0 e 1. Os parâmetros são estimados por descida do gradiente maximizando a verossimilhança.
Fórmula
P(Y=1) = 1 / (1 + e^−(β₀ + β₁X₁ + … + βₙXₙ))
Limiar: P ≥ 0.5 → Classe 1
Quando usar
Prever se um cliente vai comprar ou não (Y = 0 ou 1)
Diagnóstico médico: paciente tem ou não tem a doença
Detecção de fraudes em transações financeiras
Métricas principais
AUC-ROC McFadden R² Deviance Log-likelihood Calibração
Nível: Intermediário
〰️
Regressão Polinomial ↗ Relações não-lineares · Grau 1–6
O que é
Generaliza a regressão linear para capturar relações curvilíneas. Transforma X em potências (X², X³…) via matriz de Vandermonde e aplica OLS. O grau ideal é selecionado automaticamente pelo maior R² ajustado.
Fórmula
Ŷ = β₀ + β₁X + β₂X² + … + βₙXⁿ
Grau ótimo: max(R²_adj) sobre graus 1..6
Quando usar
Crescimento de plantas ao longo do tempo (curva sigmoide)
Consumo de combustível vs. velocidade (curva em U)
Relações biológicas ou físicas com pontos de inflexão
Métricas principais
R² por grau R² Ajustado Resíduos QQ-plot
Nível: Básico
📅
Séries Temporais ↗ Dados ordenados no tempo · Previsão
O que é
Decompõe uma série temporal em três componentes aditivos: Tendência (direção de longo prazo), Sazonalidade (padrão periódico) e Resíduo (ruído). Permite projetar valores futuros com média móvel e componentes detectados.
Fórmula
Yₜ = Tendência + Sazonalidade + Resíduo
Projeção: Ŷₜ₊ₖ = Trend(t+k) + Sazonal(t+k)
Quando usar
Projetar vendas mensais para o próximo trimestre
Analisar temperatura ou precipitação ao longo do ano
Monitorar métricas de negócio com padrões sazonais
Métricas principais
Tendência Amplitude sazonal CV (%) Média móvel Crescimento médio
Nível: Intermediário
🎻
Regressão Quantílica ↗ Distribuição completa · Robusta a outliers
O que é
Em vez de estimar apenas a média condicional, modela quantis específicos da distribuição de Y. Usa a função de perda pinball com descida do gradiente adaptativa. Ideal quando outliers distorcem a média ou quando o interesse é nos extremos da distribuição.
Fórmula
L(u,τ) = u·(τ − 𝟙[u < 0])
τ ∈ {0.1, 0.25, 0.5, 0.75, 0.9}
Quando usar
Analisar salários no percentil 90 (profissionais de alta renda)
Modelar riscos extremos em finanças ou seguros (VaR)
Dados com outliers severos onde a média é enganosa
Métricas principais
Cobertura (%) Perda pinball β por quantil Intervalo quantílico
Nível: Avançado
⚖️
Regressão Regularizada ↗ Ridge (L2) · Lasso (L1) · Anti-overfitting
O que é
Adiciona uma penalidade à função de custo do OLS para controlar overfitting com muitas variáveis. Ridge (L2) encolhe coeficientes uniformemente. Lasso (L1) pode zerar coeficientes irrelevantes, fazendo seleção automática de variáveis.
Fórmula
Ridge: β = (XᵀX + λI)⁻¹Xᵀy
Lasso: min ‖Xβ−y‖² + λ‖β‖₁
Quando usar
Muitas variáveis correlacionadas entre si (multicolinearidade)
Lasso para descobrir quais variáveis realmente importam
Dados com mais variáveis do que observações (p > n)
Métricas principais
λ ótimo RMSE por λ β encolhidos Vars zeradas R²
Nível: Avançado
💡
Como escolher o modelo certo?
Y é um número contínuo?
Use Regressão Linear (1 variável) ou Múltipla (várias). Se a relação parecer curva, experimente Polinomial.
Y é 0 ou 1 (sim/não)?
Use Regressão Logística. Ela estima a probabilidade do evento ocorrer e avalia discriminação via AUC-ROC.
Dados ordenados no tempo?
Use Séries Temporais para detectar tendência, sazonalidade e projetar valores futuros.
Muitos outliers ou quer percentis?
Use Regressão Quantílica. Ela é robusta a valores extremos e modela a distribuição completa de Y.
Muitas variáveis ou multicolinearidade?
Use Ridge para estabilizar os coeficientes, ou Lasso para selecionar automaticamente as variáveis relevantes.
