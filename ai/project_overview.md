# Project Overview

Nome: Plataforma de Regressão Linear

Descrição:
Aplicação web em um único arquivo HTML grande que contém toda a lógica do app.

Stack:
- HTML + CSS + JavaScript no mesmo arquivo
- Supabase (Auth + Database)
- PostgreSQL (via Supabase)

Arquitetura:
O projeto não usa módulos.
Todo o código está dentro de um único arquivo:
plataforma-regressaov14.html

Principais funcionalidades:
- Login e autenticação com Supabase
- Dashboard de análises
- Criar nova análise
- Abrir análise salva
- Rodar regressão linear
- Salvar resultados no banco
